First post, and a cheat sheet for how this blog works. Delete it whenever.

## writing a post

Drop a markdown file into `_posts/`, named `YYYY-MM-DD-slug.md`. Subfolders are optional and show up as directories on the [blog index](/blog/):

```
_posts/
├── meta/
│   └── 2026-10-05-hello-world.md
└── 2026-10-06-some-loose-post.md
```

Front matter is just a title:

```yaml
---
title: hello world
---
```

Code blocks get highlighted:

```golang
func main(){
  fmt.Println("Hello")
}
```

## embedding stuff

Raw HTML, scripts included, passes straight through markdown:

<details>
<summary>click me</summary>
<p>hidden until expanded</p>
</details>

<p>local time: <output id="clock">--:--:--</output></p>
<script>
  const clock = document.getElementById("clock");
  const tick = () => clock.textContent = new Date().toLocaleTimeString();
  tick(); setInterval(tick, 1000);
</script>

Add `markdown="1"` to an HTML tag if you want markdown rendered inside it. For anything you reuse across posts, put a snippet in `_includes/` and pull it in with `{% raw %}{% include snippet.html %}{% endraw %}`.

Posts go through Liquid before markdown, so wrap a literal `{% raw %}{{ }}{% endraw %}` or `{% raw %}{% %}{% endraw %}` in <code>&#123;% raw %&#125;</code> … <code>&#123;% endraw %&#125;</code> to keep it as text.
